# Цветочный магазин — REST API

Серверная часть интернет-магазина цветов. Покупатель выбирает букеты, оформляет и оплачивает заказ;
флорист собирает его, курьер доставляет; администратор управляет каталогом и смотрит статистику.

**Стек:** Java 17, Spring Boot 4.1.2 (Web MVC, Data JPA, Security), PostgreSQL, Maven, встроенный сервер Jetty.

 Подготовка базы данных

Приложение само создаёт таблицы, но нужно создать бд (имя `shop2`):

 pgAdmin: правый клик на *Databases → Create → Database…* → имя `shop2`.

Параметры подключения лежат в `src/main/resources/application.yaml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/shop2   # адрес и имя базы
    username: postgres                            # пользователь PostgreSQL
    password: ...                                 # пароль  пользователя
```



 Сервер  **http://localhost:8080**.

При первом старте пустая база автоматически заполняется демонстрационными данными (пользователи, категории, товары, склад, слоты доставки на сегодня и завтра).



Создаются автоматически при первом запуске.

| Роль | Email | Пароль |
|---|---|---|
| Администратор | `admin@shop.ru` | `admin123` |
| Флорист | `florist@shop.ru` | `florist123` |
| Курьер | `courier@shop.ru` | `courier123` |
| Покупатель | `user@mail.ru` | `password123` |


Новых покупателей можно регистрировать через `POST /api/auth/register`, а сотрудников создаёт администратор (`POST /api/admin/users`).

Ожидает оплаты → Оплачен → Принят → Собран → Доставляется → Доставлен
 (AWAITING_PAYMENT)  (PAID)  (ACCEPTED) (ASSEMBLED) (DELIVERING)  (DELIVERED)
```

- Переходы идут строго по порядку; пропустить статус нельзя (ответ 400 с текстом ошибки).
- Отменить заказ (`Отменён`, `CANCELLED`) может покупатель, пока флорист не принял его в работу.
- Остатки товаров: при оформлении заказа количество списывается с остатка, при отмене — возвращается. В корзину нельзя положить больше, чем есть в наличии; если товар закончился, пока заказ оформлялся, заказ не создаётся (400).
- Кто какой шаг делает: оплата — покупатель; «Принят» и «Собран» — флорист; «Доставляется» и «Доставлен» — курьер.

 Справочник API

Все адреса начинаются с `/api`. Ошибки приходят в виде `{"error": "текст"}` (400 — нарушено правило или неверные данные, например отрицательное количество, пустой адрес или попытка удалить товар, который уже есть в заказах; 404 — не найдено).

| Раздел | Кто имеет доступ | Что делает |
|---|---|---|
| `/auth/register`, `/auth/me` | все / только после входа | регистрация покупателя открыта всем; свои данные (`/auth/me`) — только с логином и паролем, без них ответ 401 |
| `/customer/categories`, `/products`, `/occasions`, `/colors` | все | каталог, поиск (`/products/search?q=`), хиты (`/products/popular`) |
| `/customer/delivery/slots?date=YYYY-MM-DD`, `/cart`, `/favorites`, `/orders`, `/payments` | покупатель | слоты доставки, корзина, избранное, заказы, оплата |
| `/florist/...` | флорист | профиль и смены, очередь заказов, склад и списания |
| `/courier/...` | курьер | профиль и смены, очередь доставки |
| `/admin/...` | администратор | пользователи, товары, категории, статистика |

Подробности по каждому методу — в комментариях над методами в `src/main/java/com/example/demo/controller`.
